# 記錄：Claude Code 官方 Artifacts 使用說明

整理重點：
- Claude Code 的官方 Artifacts 觸發有格式與權限限制，不一定每次都會跳出預覽。
- 需在 Claude 網頁端設定中開啟 Artifacts 功能。
- 內容要是單一獨立檔案，像 HTML、React 元件、SVG 或 Mermaid 較容易觸發。
- 提示詞要明確要求使用 Artifact 格式，否則可能只輸出一般程式碼區塊。
- 若在 CLI 看到發佈確認提示，需要同意後才會上傳並產生 claude.ai/artifacts 連結。
- 桌面版可使用 Preview 面板直接查看本機執行內容。

原始資料已一併保存，供後續查閱。
